22  最新機能の確認とマニュアルの保守

確認日：2026-11-15。本書は公式の一次資料を照合して更新しています。モデル名・価格・UI・CLIフラグ・提供条件は変わるため、確認日の情報と利用時点の情報を区別してください。

22.1 今回の主な更新

領域 旧版の問題・不足 更新内容
導入 Node.js必須、npm推奨 ネイティブ推奨とOS別の注意
権限 全操作を必ず確認するような説明 Manual/default、auto、事前許可と隔離を区別
記憶 セッション間の記憶がないという断定 自動メモリ・明示指示・読込の違い
スキル・hooks 小文字skill.md、未定義変数、終了コードの誤り SKILL.md、標準入力JSON、終了2と失敗時方針
MCP 古いサーバー例、患者DBの危険なサンプル 現行GitHub公式経路、固定教材の例
上級運用 権限省略と破壊的な再試行、未出典の倍率 限定実験、測定、停止・復旧
クラウド 旧–remote、提供条件の固定 –cloud、現行の接続と環境別の検証
協働 他社AIとの手順不足 Codex・Gemini、受け渡し票、独立検証
制作 画像・動画生成の説明不足 現行提供状況、UI/API、絵コンテ、品質管理
医療・安全 実務と組織導入の不足 医師向け実践、機密・事故対応、段階演習

22.2 利用前の確認手順

claude --version
claude --help
codex --version
codex exec --help
gemini --version
gemini --help

CLIのヘルプは構文の証拠です。実行権限、契約、API利用資格、ネットワーク到達性がある証拠ではありません。本文の最小例で無害な試験を行います。

2026-11-15のローカル照合環境：Claude Code 2.1.325、Codex CLI 0.166.0、Gemini CLI 0.42.0、Quarto 1.8.27。これは最新バージョンを固定して推奨する一覧ではありません。

22.3 機能を使い分ける

機能 確認すること 公式資料
Agent Teams 実験機能、費用、再開・協調の制約 Teams
自動メモリ 保存内容、読込、共有範囲 Memory
auto mode 提供条件、判定、管理設定 Permissions
Remote Control 実行は元の端末、接続・失効 Remote Control
クラウドセッション –cloud、認証、設定、送信先 Cloud
定期実行 生存期間、停止、上限 Schedule
診断モード カスタマイズ無効化の範囲 CLI reference

--safe-modeはカスタマイズ由来の問題を切り分ける手段です。通常のツールや権限が残るため、「完全に安全な閲覧モード」と解釈しません。新機能を見つけても、ただちに本番へ有効化せず適用範囲を試験します。

22.4 保守の頻度

本書の提案として、月次でリンクと変更履歴を確認し、導入・モデル移行・契約更新・組織展開の前にも再確認します。特に権限、hooks、MCP、認証、データ保持、画像動画モデルの終了告知を優先します。

更新時は「機能・現在の記述・公式URL・確認日・利用版・確認結果」を記録します。公式ドキュメント内の古いサンプルよりも、現在の提供状況と廃止告知を優先します。確認できない場合は未確認と明記し、実行例から外します。

22.5 この本を更新する人へ

正本はルートの.qmdと_quarto.ymlです。docs/は生成済みサイトです。原稿だけ直しても、現在のPagesワークフローは自動ビルドしないため公開内容は変わりません。

quarto render --to html

出力HTMLの目次・章間リンク・コード・スマホ幅の表を確認します。変更した原稿と生成物を合わせてレビューし、公開は承認後に行います。差分にAPIキー・個人情報・開発機の非公開パスがないか確認してください。
