2026年11月15日

はじめに

このマニュアルのゴール

Claude Codeを初めて使う人から、高度な協働や自動化を設計する人まで、自分の作業を安全に限定し、成果を検証しながら最大限に活用できることを目指します。医師・医療チームにも使える、公開資料・架空データ・合成データの実例を含みます。

最終確認日：2026-11-15。 元の16章を点検し、公式資料と照合して修正し、6章を追加しました。価格・提供条件・モデル・コマンドは変わります。更新と保守で確認方法を説明します。

Important最初に安全対策を読む

安全対策の「開始前の5項目」を確認してください。練習には公開・架空データを使います。ローカルCLIでも、読み込んだ情報がモデルや外部ツールへ送られることがあります。患者情報や本番の秘密鍵を練習環境へ入れません。

読み方

読者 おすすめの順序 到達点
初心者 安全対策→第1〜4章→演習1・2 起動、依頼、権限確認、差分確認
中級者 第5〜11章→第18・19章 再利用と外部接続、複数AI、画像動画
上級者 第12〜17章→第22章 評価、自動化、隔離、監視と復旧
医師・医療チーム 初級ルート→第20章→演習7 原典照合、教材作成、合成データ解析

章ごとの実践を終えたら、段階別演習と到達度チェックで「説明できる」「検証できる」「停止できる」を確認してください。

構成

  • Part 1〜2：導入、基本操作、CLAUDE.mdとメモリ
  • Part 3〜5：サブエージェント、協働、コマンド・スキル・hooks、MCP
  • Part 6〜8：チーム展開、ハーネス、反復、Web・クラウド
  • Part 9：安全対策、Codex・Geminiとの協働、画像・動画制作
  • Part 10：医師向け実践、段階演習、更新と保守

本書の役割分担や運用上限は、特記しない限り実践上の提案です。公式機能や製品の保証とは区別します。コードは前提と適用範囲を読んでから使い、実行していない機能や有料生成を検証済みと扱いません。
